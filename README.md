# Sistema-Solar
Uma aplicação web interativa sobre o Sistema Solar, desenvolvida com HTML, CSS e JavaScript. O projeto permite explorar visualmente os oito planetas do Sistema Solar e consultar informações sobre cada um deles.
A aplicação foi desenvolvida com foco em uma experiência visual, interativa e multimídia, utilizando animações, efeitos visuais e recursos de áudio disponíveis no navegador.
