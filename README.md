Sistema Solar Interativo

O que criamos
Criamos uma aplicação web interativa sobre o Sistema Solar, onde o usuário pode visualizar os planetas em movimento e clicar em cada um para consultar suas principais informações e curiosidades.

Ideia
A ideia foi criar uma aplicação educativa e interativa, utilizando recursos multimídia para tornar a exploração do Sistema Solar mais visual e interessante.

Mídias utilizadas
* Elementos visuais dos planetas, Sol e estrelas;
* Animações das órbitas e efeitos visuais;
* Textos com informações e curiosidades;
* Síntese de voz para leitura das informações.

Uso da IA ChatGPT
A Inteligência Artificial foi utilizada como ferramenta de apoio para auxiliar na criação e organização dos códigos e desenvolvimento das animações.

Ferramentas utilizadas

* HTML5 — estrutura;
* CSS3 — design e animações;
* JavaScript — interações e funcionalidades;
* Visual Studio Code — desenvolvimento;
* Google Chrome — testes;
* GitHub — armazenamento do projeto.

O que aprendemos

Durante o desenvolvimento, aprendemos a integrar HTML, CSS e JavaScript para criar uma aplicação interativa, além de trabalhar com animações, eventos de clique, manipulação de elementos, responsividade e recursos de áudio.
Também aprendemos sobre a importância de combinar funcionalidade, design e experiência do usuário na criação de uma aplicação multimídia.
